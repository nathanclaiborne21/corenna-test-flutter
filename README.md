# corenna-test-flutter

A test app for Corenna's Flutter build pipeline: the unmodified counter app
from `flutter create` (Flutter 3.47.7 stable, Kotlin DSL Android project).

Kept as close to a brand-new Flutter project as possible, so a passing build
here means a new Flutter user's first build works.

Last test build: November 22, 2026, a signed release APK in 4 minutes. This
line was committed through Corenna's Build Space, as a test of it.
